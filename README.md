# BMP File Rename

BMPファイルを一括でリネームするためのシンプルなTkinterアプリです。

指定フォルダ内のBMPファイルをファイル名順に取得し、テキストファイルに定義された名前を使って、3桁の連番付きファイル名へ一括変更します。

## 概要

例えば、対象フォルダに以下のBMPファイルがある場合、

``` text
ABC.bmp
DEF.bmp
XYZ.bmp
```

ファイル名一覧として以下のテキストファイルを指定します。

``` text
sample_big
sample_normal
sample_small
```

実行すると、以下のようにリネームされます。

``` text
001_sample_big.bmp
002_sample_normal.bmp
003_sample_small.bmp
```

連番の開始番号はアプリ上で任意に指定できます。

初期値は `1` です。例えば開始番号を `10` にすると、

``` text
010_sample_big.bmp
011_sample_normal.bmp
012_sample_small.bmp
```

のようにリネームされます。

------------------------------------------------------------------------

## 主な機能

-   ダイアログから対象フォルダを選択
-   対象フォルダ内のBMPファイルを取得
-   BMPファイルをファイル名順にソート
-   ダイアログからファイル名一覧（`.txt`）を選択
-   対象フォルダとファイル名一覧はパスの直接入力・貼り付けにも対応
-   Windowsの「パスのコピー」で付くダブルクォーテーション付きパスにも対応
-   ファイル名一覧を1行ずつ読み込み
-   連番の開始番号を任意に指定可能
-   `連番_ファイル名.bmp` の形式で一括リネーム
-   BMPファイル数とファイル名一覧数の一致チェック
-   Windowsで使用できないファイル名文字のチェック
-   リネーム完了件数をダイアログ表示

------------------------------------------------------------------------

## ファイル名一覧

ファイル名一覧はUTF-8のテキストファイルを使用します。

1行につき1つのファイル名を記述します。

例：

``` text
sample_big
sample_normal
sample_small
```

`.bmp` の拡張子や連番を記述する必要はありません。

アプリ側で自動的に、

``` text
001_sample_big.bmp
002_sample_normal.bmp
003_sample_small.bmp
```

の形式へ変換します。

連番の開始番号はアプリ上で変更できます。

空行は無視されます。

------------------------------------------------------------------------

## パスの入力

「対象フォルダ」と「ファイル名一覧」は、「参照...」ボタンから選択するほか、パスを直接入力・貼り付けできます。

Windowsのエクスプローラーで「パスのコピー」を使用すると、次のようにパスがダブルクォーテーションで囲まれる場合があります。

``` text
"C:\work\images"
"C:\work\file_names.txt"
```

この形式のまま貼り付けても使用できます。

もちろん、ダブルクォーテーションのない通常のパスも使用できます。

------------------------------------------------------------------------

## リネーム順序

対象フォルダ内のBMPファイルは、ファイル名でソートしてからファイル名一覧と対応付けます。

例えば、

``` text
A.bmp
B.bmp
C.bmp
```

と、

``` text
big
normal
small
```

の場合、

``` text
A.bmp → 001_big.bmp
B.bmp → 002_normal.bmp
C.bmp → 003_small.bmp
```

となります。

## 安全対策

### ファイル数のチェック

BMPファイル数とファイル名一覧の数が一致しない場合は、リネームを実行しません。

例えば、

``` text
BMPファイル数: 10
ファイル名数: 9
```

の場合はエラーダイアログを表示して処理を終了します。

### ファイル名のチェック

Windowsのファイル名として使用できない以下の文字が含まれている場合は、処理を中止します。

``` text
< > : " / \ | ? *
```

### 一時ファイル名を使用したリネーム

元のファイル名と新しいファイル名の衝突を避けるため、リネームは2段階で行います。

``` text
ABC.bmp
DEF.bmp
XYZ.bmp
    ↓
__rename_temp_001.tmp
__rename_temp_002.tmp
__rename_temp_003.tmp
    ↓
001_sample_big.bmp
002_sample_normal.bmp
003_sample_small.bmp
```

------------------------------------------------------------------------

## 注意事項

このアプリはリネーム前のBMPファイルをバックアップしません。

実行すると元のファイル名は変更されます。

重要なBMPファイルを扱う場合は、必要に応じて事前に別の場所へコピーしてください。

また、対象フォルダ直下の `.bmp`
ファイルを処理対象とします。サブフォルダ内のBMPファイルは対象になりません。

## 実行方法

プロジェクトフォルダで以下を実行します。

``` bash
python app.py
```

アプリが起動したら、

1.  「対象フォルダ」の「参照...」からBMPファイルが保存されているフォルダを選択、またはパスを貼り付け
2.  「ファイル名一覧」の「参照...」からテキストファイルを選択、またはパスを貼り付け
3.  「連番開始番号」を入力（初期値は `1`）
4.  「ファイル名変更」をクリック
5.  完了ダイアログを確認

以上でリネーム完了です。

## 使用ライブラリ

以下はすべてPython標準ライブラリです。

-   `tkinter`
-   `pathlib`

`tkinter`
はGUI、ファイル・フォルダ選択ダイアログ、メッセージ表示に使用します。

`pathlib` はBMPファイルの取得、パス操作、リネーム処理に使用します。
